# Обработка заявлений на услуги

Это учебное приложение на Windows Forms, похожее на сервис подачи заявлений на госуслуги. Например, гражданин заполняет профиль и подаёт заявление, а служащий открывает его и запускает проверку по правилам выбранной услуги.

## Что можно сделать

| Роль | Возможности |
| --- | --- |
| Гражданин | Заполнить профиль, выбрать услугу, подать заявление и посмотреть свои заявления. |
| Служащий | Открыть заявление и запустить проверку. Приложение сравнит данные гражданина с правилами услуги и рассчитает срок, если он задан в правилах. |
| Администратор | Создавать пользователей и настраивать услуги, поля профиля и правила проверки. |

## Устройство проекта

Приложение написано на C# для .NET 8 под Windows. Когда пользователь нажимает кнопку в форме, контроллер вызывает нужный сервис. Сервисы обрабатывают заявления, а репозитории читают и сохраняют данные в PostgreSQL через EF Core и Npgsql. Формы и сервисы связывает контейнер Microsoft DI.

## Локальный запуск

Для запуска нужны Windows, .NET 8 SDK и PostgreSQL с подготовленной схемой и учётными записями для нужных ролей. В локальном файле `program/gos/gos/appsettings.json` задайте строку подключения `ConnectionStrings:DefaultConnection`. Затем откройте решение в Visual Studio с поддержкой классических приложений .NET или запустите проект из корня репозитория.

```sh
dotnet run --project program/gos/gos/gos.csproj
```
